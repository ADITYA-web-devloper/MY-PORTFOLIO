# Aditya Sada Shankar — Portfolio

Personal portfolio for a Computer Science Engineering graduate focused on frontend development and currently learning backend development.

## Run locally

1. Extract the ZIP.
2. Open this folder in VS Code.
3. Open `index.html` with Live Server, or serve the folder using any static HTTP server.

## Portfolio content

- Frontend development focus: HTML, CSS, JavaScript, responsive design, CSS Grid, Flexbox, React, Git, and GitHub.
- Backend learning: Node.js, Express.js, REST APIs, MySQL fundamentals, and authentication basics.
- Projects and screenshots carried over from the previous portfolio.
- Contact and social links retained from the previous portfolio.

## Scroll/performance fixes

- The custom cursor updates only on pointer movement instead of running a permanent animation-frame loop.
- Scroll reveal animations run once instead of replaying on every scroll.
- Project carousel autoplay is disabled; visitors can still navigate projects manually.
- Animations respect the operating system's reduced-motion setting.
